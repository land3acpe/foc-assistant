# FOC-Assistant 知识库

直接把文件丢进对应文件夹，Agent 会自动索引。

## 目录说明

| 文件夹 | 放什么 | 支持格式 |
|--------|--------|----------|
| `papers/` | 参考论文 | .pdf（自动提取全文） |
| `data/` | 实验数据 | .csv（自动索引列名） |
| `notes/` | 技术笔记、公式、经验 | .md .txt（全文索引） |

## 三种添加方式

### 方式 1：直接拖文件（推荐）
把 PDF/CSV/MD 文件复制到对应文件夹，然后对 Agent 说：
> "重建知识库索引"

### 方式 2：让 Agent 帮你导入
> "帮我把桌面上的 FTESO-STSM.pdf 导入到知识库"

### 方式 3：口述让 Agent 记录
> "把这段经验存到知识库：电流环 Kp 不要超过 L*wc 计算值的 1.5 倍"

## 索引内容

- **PDF**：提取前 10 页正文→全文搜索
- **CSV**：列名 + 行数 + 数值列统计
- **MD/TXT**：全文索引
